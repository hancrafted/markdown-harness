A list nested inside a list item belongs to the outer list and is not a block of its own. The bulleted list and the numbered list inside the first two items are part of the one numbered list, so the section holds one block, of the kind the entry lists.

## Ordered

1. First.
   - A bullet inside it.
   - Another.
2. Second.
   1. A numbered item inside it.
3. Third.
