# Labels

`docs/reference/` sets `descriptionSource: labels.md`, so THIS file's description is what
`docs/index.md` copies for the `reference/` folder entry — while the folder entry still links
`reference/index.md`, never this file. `index.md` is the progressive-disclosure container;
a descriptor is only ever read from.
