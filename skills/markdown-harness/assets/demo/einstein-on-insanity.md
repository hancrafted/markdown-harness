# Doing the same thing twice

The line most often put in Einstein's mouth says that insanity is doing the same thing over and over
and expecting a different result. He almost certainly never said it — the earliest printed
appearances are in recovery literature, decades after his death — but the idea outlived the
misattribution, because it is a claim about process rather than about the man.

Repetition without variation cannot produce information. If nothing about an attempt changes,
nothing about its outcome can reasonably be expected to, and a second run of an unchanged experiment
measures only the patience of whoever is running it.

The useful corollary is smaller than the slogan: before repeating anything, name the one thing you
are changing. If you cannot name it, you are not running a second attempt. You are running the first
one again.
